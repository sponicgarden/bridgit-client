# site-content

Published content that the Bridgit apps use and that bridgit.cc also serves.
The website itself (pages, Worker, accounts, styles) is in the private
`sponicgarden/bridgit-cloud` repo; its build copies this folder from a public
checkout.

- `public/learn/`, `public/llms.txt`: agent docs, written from the app's
  catalogs by `tools/refresh-learn.sh` (LearnTest fails while they are stale).
- `public/demo/SKILL.md`: the first-run tour (copied into the APK; GET /v1/demo).
- `public/samples/`: sample cards. `samples.json` is built from
  `content/samples.json` and the card pages by `node site-content/scripts/samples.mjs`;
  the APK and the iOS app bundle it (GET /v1/samples).
- `content/builder/`, `public/recipes/`: applet recipes and their applet files,
  built by `node site-content/scripts/builder-recipes.mjs` (which also writes the
  app's `AppletBuildGuide.kt`).
- `content/interactions/`: interaction examples for the website's library page.
- `content/backend-api.json`: generated by the private backend repo
  (`tools/public-snapshot.mjs`). Never edit it by hand.

Tests: `node --test site-content/tests/*.test.mjs`. Prompt hashes:
`node site-content/scripts/prompt-integrity.mjs`.
