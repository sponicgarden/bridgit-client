RecipesBuilder guideAPI reference

Build with Bridgit

Seven small applets, each one file with a card the phone draws itself, plus API examples. Start from a goal; check the installed device’s guide and grants before running it. Nothing on this page grants access or starts a device action: Import opens a review on your phone, and nothing runs until you approve it there.

Documentation revision 1; API contract reference 54. Source, published, installed and ready are separate states. See the native-versus-composable matrix and build guide.

v1.watches · v1.camera · v1.interactions

Pet activity monitor

A photo-based activity tally with explicit gaps, plus an offline control card.

Public composition is a generic watch, not the native Pet Monitor. It does not inherit native camera selection, dual-model comparisons, pet history/portal, microphone classifier, camera search or feeding.

v1.ocr · v1.gallery · v1.interactions

Receipt scanner

Read a selected receipt locally, check the text and save it on the phone.

OCR text is not a verified accounting record. This recipe does not pay, submit expenses, or infer a currency.

v1.mic · v1.interactions

Voice notebook

Record one bounded offline transcript, check the words and save the note on the phone.

Not an always-listening notebook. It captures only a bounded clip on a deliberate tap.

v1.watches · v1.camera · v1.interactions

Room change watcher

A free image-change trigger with an explicit interpretation boundary.

A changed image is not an intrusion, person count, danger or proof that something happened outside the frame.

v1.schedule · v1.weather · v1.interactions

Daily briefing panel

An owner-approved reminder and a card that reads current weather on demand.

The local schedule cannot template arbitrary API responses into rich HTML. A fresh multi-source digest needs controller code to gather, summarize and publish a new card.

v1.lan_control · v1.interactions

External device dashboard

List only the agent’s enrolled LAN devices; keep availability honest.

Listing does not test devices: availability=not_checked is not online. Discovery is partial and unverified; enrollment is separate.

Situation counter

Spot and count one camera situation, like a pot boiling over or a dog licking itself.

A count is sampled photos judged by a model, not continuous coverage or proof: gaps, a locked camera or the thing being out of frame are unknown, not zero.
