Records ten seconds only when you tap. Review the words before saving. Saved notes stay on this phone.

Applet file · Older HTML card in the card simulator · Complete HTML interaction body · Machine-readable recipe

What runs where

  • Explicit owner tap → 10-second microphone clip → installed Android on-device speech recognizer → editable notebook draft → one answer.
  • No cloud fallback. The card can capture/transcribe without the controller, but saving the notebook requires the controller or another explicitly authorized storage integration.

Controller integration

  • Controller persists returned transcript only after the owner answers. Do not store credentials or notebooks in example pages.

Only explicit decision-model/weather requests leave the phone; direct or relay transport still requires a running reachable phone.

Boundaries

  • Not an always-listening notebook. It captures only a bounded clip on a deliberate tap.
  • On-device recognition availability depends on Android and installed language resources. Empty transcript is not silence evidence.

Lifecycle

start

Configure card data, POST the generated HTML interaction; this does not automatically capture or poll.

update

Owner explicitly refreshes; controller stores approved data and posts a replacement card as needed, cancelling old pending cards.

pause

The Pause button suspends this card’s controls and suppresses results from a pending refresh. There is no background job in this starter; an in-flight capture may finish. Controller integrations must separately pause their jobs.

stop

The Stop button stops this card, suppresses late results, and requests controller shutdown through one response. Confirm/close the controller job and DELETE the interaction separately. Local stop is not proof that an external process stopped.

Failures and costs

  • No offline recognizer: not_supported before recording. Unsupported language or capture error: show the actual error and let the owner retry.
  • With return_audio=false, transcription failure fails the request; there is no audio fallback to upload.
  • No Jev/Clef call. Local microphone and speech consume battery; keep clips bounded.

Extensions

  • Add a separate optional controller summarizer after the owner approves the transcript.
  • Use the separate owner-enabled wake-word system for hands-free collection; that is not silently enabled by this recipe.
